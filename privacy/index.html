2. 取得・保存する情報

本アプリは、次の情報を取り扱うことがあります。

区分内容の例保存場所
Google サインイン 利用者 ID、メールアドレス。Google の表示名はランキングの公開名に使わない Supabase Auth、および端末内のセッション
プロフィール 表示名、紹介文、性別、年代、体重 端末内 SQLite。バックアップ利用時はクラウドのバックアップにも含まれる
ワークアウト履歴 実施日、種目名、セット、重量、回数、時間・距離、メモ 端末内 SQLite。バックアップ利用時はクラウドのバックアップにも含まれる
称号 獲得・装備中の称号 端末内 SQLite。装備中の称号はランキング参加中にクラウドへ公開される
進捗写真 画像ファイル、撮影日時、保存パス 画像ファイルは端末内のアプリ私有領域。撮影日時とパスは SQLite。クラウドへは送らない。バックアップの SQLite にはパスと撮影日時が含まれ得るが、JPEG 本体は含まれない
公開アイコン ランキング参加中に保存したプロフィール画像。256px と 512px の JPEG 端末内のアプリ私有領域。参加中の保存で Supabase Storage の profile-icons（公開バケット）
ランキング 表示名、紹介文、順位、装備称号、部位のぱわぁ、直近4サイクルの完了セット履歴 サインイン済みで性別と年代がある利用者は、ランキング同期で名簿へ入る。クラウドは Supabase Postgres
バックアップ SQLite ファイル全体。体重、性別、年代、メモ、種目名、写真のパスと撮影日時、その他 SQLite に保存される利用者データを含み得る。進捗写真の JPEG 本体は含まない Supabase Storage の backups/{利用者ID}/latest.gogymbk。本人のみ読み書きできる
製品改善のセット記録 公式種目の ID、自作種目の名前と部位、重量、回数、RIR、有酸素の距離と時間。サインイン中に、保存済みのセットを送る。サインインしていないあいだは送らない Supabase Postgres の非公開の表。他の利用者には見せない。アプリの画面では読まない
アプリ設定 表示単位、通知など 端末内

本アプリは、次を行いません。

  • 広告 SDK、アクセス解析 SDK、クラッシュ収集 SDK の組込み
  • 広告目的でのデータ収集
  • 氏名・住所・電話番号の必須取得
  • トレーニング記録の販売
  • 進捗写真のクラウド送信。端末の写真アプリへの追加は、利用者が「ギャラリーへコピー」したときだけ
  • ランキング未参加のプロフィール画像のクラウド送信
  • Google アカウントの表示名をランキング公開名として使うこと

3. ランキングで他の利用者に見えるもの

サインイン済みで、性別と年代が入力されている利用者は、ランキングの同期により名簿へ参加します。参加するかどうかの個別スイッチはありません。

他の利用者に見えるもの:

  • 表示名
  • 紹介文
  • 順位
  • 装備中の称号
  • 参加中に保存したプロフィール画像
  • ランキング詳細の部位ぱわぁ
  • 直近4サイクルの完了セット履歴（実施日、種目名、セット、重量、回数、RIR、詳細設定。有酸素は距離・時間。RIR が空のセットには RIR を出さない）

他の利用者に見せないもの:

  • メールアドレス
  • 性別
  • 年代
  • 体重
  • メモ
  • 進捗写真とそのデータ
  • 開始時刻と終了時刻

公開アイコンは、ランキングに参加している人がプロフィール画像を保存したとき、名簿へ出ます。別の公開同意はありません。保存先の profile-icons は公開バケットです。URL を知っている人は、アプリの外からその画像を取得できます。

4. 利用目的

  • 記録、履歴、統計、分析、進捗写真の比較
  • 上記の条件でのランキング表示
  • クラウドバックアップと復元
  • アカウントと端末の紐付け
  • 種目と記録の基準を、製品側で改善すること。セット記録は販売せず、他の利用者には見せない
  • 通知と表示の維持
  • カメラと写真へのアクセスは、進捗写真の撮影・取り込み、ギャラリーへのコピー、プロフィールアイコンの取り込みに使う

5. 保存場所・保管期間・削除

  • 端末内データ: アプリ内のアカウント削除、またはアプリ／OS のデータ削除まで
  • 進捗写真: 原則として端末内。クラウドへは送らない。ギャラリーへコピーした写真は写真アプリ側に残る。アプリ内の削除やアカウント削除では、そのコピーは消えない
  • 公開アイコン: 端末内のファイルに加え、参加中に保存したクラウド公開分。ランキング離脱とアカウント削除でクラウドのオブジェクトを消す。公開バケットのため、削除前に URL を知っていた第三者の手元に残った複製までは消せない
  • バックアップとランキング: アカウントが存続する間。アカウント削除で、本人のバックアップ、名簿、公開履歴、シーズン結果、アイコン通報を消す
  • 製品改善のセット記録: アカウント削除で、その行とアカウントの結びつきは消す。セットの中身は、誰の記録か分からない状態で残す。自作種目の名前も残る。アプリでセットを消しても、この記録は消えない
  • アプリ内の削除: 設定のアカウントから「アカウントを削除」を実行すると、次を削除します。GoGym のクラウドアカウント、ランキング情報、公開履歴、公開アイコン、クラウドバックアップ、端末内の GoGym データ（トレーニング記録、プロフィール、アプリ私有領域の写真）。製品改善のために送ったセットの記録は、アカウントと切り離して残ります。削除の途中で失敗した場合、アプリは「アカウントを削除しました」とは表示しません
  • 削除後の再ログイン: 同じ Google アカウントで入り直した場合、新しい GoGym 利用者として扱い、削除前のクラウドデータは戻りません。Google アカウントそのものは削除しません
  • アプリを消したあと: アカウント削除のページから、同じメールアドレス宛に削除を依頼できます。メールでの依頼は自動では消えず、運営が確認して対応します

6. 第三者提供・処理委託

法令に基づく場合を除き、利用者の情報を販売することはありません。

処理の委託先:

  • Google（Google サインイン、Google Play を通じた配布）
  • Supabase（Auth、Postgres、Storage）

広告ネットワークへの提供はありません。詳細は Google のプライバシーポリシー と Supabase のプライバシーポリシー をご確認ください。
